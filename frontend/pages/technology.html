Under the Hood

The Technology

A deep dive into the multi-signal fusion architecture that powers DeepScan's detection engine.

Detection Architecture

DeepScan AI combines a fine-tuned deep neural network with six independent computer vision signal analyzers. Each signal captures a different dimension of video authenticity — from pixel-level compression artifacts to high-level temporal motion patterns. The outputs are fused into a single confidence score and verdict.

This hybrid approach outperforms single-model detectors because deepfake generation methods vary widely. A GAN-based face swap may fool a temporal analyzer but leave compression artifacts; a diffusion-based synthesis may pass artifact checks but fail face quality scoring. Fusion catches what any single signal misses.

EfficientNet-B4 Feature Extractor

The primary AI component is EfficientNet-B4, a convolutional neural network pretrained on ImageNet (1.2 million images, 1000 classes). It is used as a feature extractor — not trained on deepfake data, but its rich visual representations are used to measure frame-to-frame consistency.

Each face crop is converted into a 1792-dimensional feature vector. Cosine similarity between consecutive frame vectors detects GAN instability — real videos have stable features (0.90–0.99), deepfakes have erratic features (0.65–0.85) because GANs regenerate each frame independently.

  • Architecture: EfficientNet-B4 (PyTorch, timm library)
  • Parameters: 19 million
  • Input: 224×224 RGB face crops
  • Output: 1792-dim feature vector per frame
  • Weight: 45% of final suspicion score

5-Signal Computer Vision Fusion

Each signal is computed independently using OpenCV and contributes to the final suspicion score.

Signal 1 — EfficientNet Deep Features (45%)

Cosine similarity between consecutive frame feature vectors. Real: mean_sim 0.90–0.99, std < 0.05. Deepfake: mean_sim < 0.78 AND std > 0.06 triggers suspicion.

Signal 2 — Texture Variance / Laplacian (20%)

Laplacian operator measures face sharpness per frame. Coefficient of variation > 0.55 or mean sharpness < 80 indicates inconsistent texture — a deepfake artifact.

Signal 3 — Face Blend Seam / Sobel (15%)

Sobel gradient at face boundary. Border-to-inner gradient ratio > 2.0 indicates a blending seam — the signature of face-swap deepfakes where a face is pasted onto a body.

Signal 4 — Color Mismatch / LAB (15%)

LAB color space comparison between face region and background. Difference > 0.25 indicates the face came from a different source with different lighting or camera.

Signal 5 — Temporal Flicker (5%)

Frame-to-frame pixel difference coefficient of variation. Real: CV 0.15–0.65. Deepfake: CV > 0.85 (erratic GAN output) or < 0.08 (frozen/static face).

Weighted Fusion

Suspicion = S1×0.45 + S2×0.20 + S3×0.15 + S4×0.15 + S5×0.05. Face weight = 1.0 if face detected, 0.4 if not. Threshold 38 → FAKE, below → REAL.

Processing Pipeline

When a video is submitted, the backend executes the following pipeline:

  • Frame Extraction: User-selected number of frames (10–60) evenly sampled using np.linspace across the full video duration.
  • Face Detection: OpenCV Haar Cascade (haarcascade_frontalface_default) isolates face regions with 20% padding. Falls back to center crop if no face found.
  • EfficientNet Inference: PyTorch EfficientNet-B4 converts each 224×224 face crop to a 1792-dim feature vector. Cosine similarity computed between consecutive frames.
  • CV Signal Computation: Laplacian sharpness, Sobel boundary gradient, LAB color mismatch, and temporal pixel difference computed on face crops.
  • Weighted Fusion: Five signal scores combined with fixed weights into a suspicion score 0–100.
  • Verdict: Suspicion ≥ 38 → FAKE. Confidence mapped from suspicion score range.
