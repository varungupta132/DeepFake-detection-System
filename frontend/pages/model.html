Model Architecture

The core model is MobileNetV2 with a custom classification head fine-tuned for binary deepfake detection. The architecture was chosen for its balance of accuracy and inference speed, making it suitable for real-time video analysis without requiring GPU acceleration.

Base: MobileNetV2

Pre-trained on ImageNet, providing rich visual feature representations as a starting point for fine-tuning on deepfake-specific patterns.

Custom Head

Global average pooling → Dense(256, ReLU) → Dropout(0.3) → Dense(2, Softmax). Outputs real/fake probability distribution.

Input Resolution

224×224 RGB frames. Face regions are cropped and resized before inference to focus the model on facial manipulation artifacts.

Aggregation

Per-frame predictions are aggregated using a weighted mean, giving higher weight to frames with higher face detection confidence scores.

Training Methodology

The model was trained using a two-phase approach:

  • Phase 1 — Feature Extraction: The MobileNetV2 base was frozen and only the classification head was trained for 10 epochs, allowing the head to adapt to the deepfake detection task.
  • Phase 2 — Fine-tuning: The top layers of the base were unfrozen and the entire model was trained end-to-end with a low learning rate (1e-5) for 20 additional epochs.
  • Data Augmentation: Random horizontal flips, brightness/contrast jitter, and JPEG compression simulation were applied to improve robustness.
  • Loss Function: Categorical cross-entropy with label smoothing (0.1) to prevent overconfident predictions.
  • Optimizer: Adam with cosine learning rate decay schedule.

Signal Fusion Strategy

The neural model output is combined with the six CV signal scores using a learned weighted fusion. Weights were determined through a grid search on a validation set, optimizing for F1 score.

The final suspicion score is computed as:

suspicion = 0.35 × tf_score + 0.15 × temporal + 0.12 × compression
            + 0.12 × face_quality + 0.10 × edge + 0.10 × color + 0.06 × motion

A suspicion score above 50 triggers a FAKE verdict. The confidence percentage reflects how far the score is from the decision boundary, normalized to a 0–100% range.

Known Limitations

No detection system is perfect. DeepScan AI has the following known limitations:

  • Performance may degrade on very low-resolution videos (below 240p)
  • Heavily compressed or re-encoded videos can reduce signal quality
  • Novel generation methods not represented in training data may achieve lower detection rates
  • Videos with no detectable faces fall back to frame-level analysis only
  • Very short clips (under 2 seconds) provide limited temporal signal
